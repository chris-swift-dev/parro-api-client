Quick start

Ask Claude (MCP server)

Ask “Do I need to do anything for school in the coming weeks?” and Claude reads Parro for you. With the package installed, in Claude Code:

claude mcp add parro -s user -- parro-client-mcp

Tools that change something are off unless you switch them on.

Safe by design

  • On your computer. It talks to Parro directly. There is no server in between, and no account other than your Parro login.
  • Changes only when you ask. It can mark as read, send a chat message, sign you up as a helper and answer an invitation, each only after you confirm.
  • No telemetry. Nothing about you or your school is sent anywhere else. The desktop app's check for new versions is optional and asks GitHub only.
  • Your password stays yours. It is not stored; a login lasts up to 8 hours.
